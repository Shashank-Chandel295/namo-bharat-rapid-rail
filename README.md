# Namo Bharat Rapid Rail

A frontend web project for a Namo Bharat Rapid Rail ticketing and journey management interface.

## Features

- Ticket Booking
- Route & Fare
- Train Schedule
- User Login
- Dashboard
- Digital Ticket
- Notifications
- Dark Mode
- Hindi / English
- Responsive Mobile Design

## Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub
