# 🚆 Namo Bharat Rapid Rail

A modern web-based Namo Bharat Rapid Rail ticket booking and passenger management system.

## 📌 Project Overview

Namo Bharat Rapid Rail is a frontend web application designed to provide passengers with a simple and modern railway booking experience.

The project includes ticket booking, fare calculation, payment simulation, digital tickets, QR/barcode ticket display, notifications, profile management and responsive dashboard features.

## ✨ Features

- 🔐 User Login & Session Management
- 🏠 Passenger Dashboard
- 🎫 Ticket Booking
- 🛤️ Route Selection
- 📅 Journey Date Selection
- 👥 Passenger Selection
- 💰 Automatic Fare Calculation
- 💳 Payment Page
- ✅ Payment Success Page
- 🎟️ Digital Travel Ticket
- 🔳 QR / Barcode Ticket
- 🔔 Notification System
- 👤 User Profile
- ✏️ Edit Profile
- 🔑 Change Password
- ⚙️ User Settings
- 🌙 Dark Mode
- 🌐 Hindi / English
- 📱 Responsive Mobile Design
- 💾 LocalStorage Data Management
